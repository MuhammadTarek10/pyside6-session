# 04 — App with resources (icons, images, stylesheet)

An image viewer with a toolbar, menus, icons, a logo and a stylesheet. **All assets are
compiled into Python** through the Qt Resource System.

```bash
./build.sh 04_resources            # rcc + uic
python 04_resources/main.py
```

## Why resources?
`QIcon("icons/open.svg")` is a **relative path**. It breaks when you run the app from a
different folder, or after packaging it into an `.exe`/`.app`. With resources, files are embedded
in a Python module and accessed through a virtual file system that starts with `:/`:

```python
QIcon(":/icons/open.svg")
QPixmap(":/images/logo.svg")
QFile(":/styles/style.qss")
```
Resource paths work anywhere Qt accepts a file path (`QIcon`, `QPixmap`, `QFile`, QSS `url(...)`).
**Python's `open()` does not understand `:/`**. Use `QFile` for that.

## Files in this folder
```
resources.qrc        # XML manifest: which files, under which prefix
icons/*.svg          # toolbar icons (SVG scales crisply on High-DPI)
images/logo.svg      # window icon + default image
styles/style.qss     # Qt Style Sheet
resources_rc.py      # GENERATED by pyside6-rcc (contains the bytes)
main_window.ui       # Designer form, uses icons via the Resource Browser
ui_main_window.py    # GENERATED by pyside6-uic
main.py              # our code
```

## The `.qrc` file
```xml
<qresource prefix="/icons">
  <file alias="open.svg">icons/open.svg</file>   <!-- → :/icons/open.svg -->
</qresource>
```
- `prefix` is a virtual folder. `alias` is the name inside it (without an alias it would be
  `:/icons/icons/open.svg`).
- Paths are relative to the `.qrc` file.

## Designer workflow
1. In Designer's **Resource Browser** (View → Resource Browser) → ✏️ → *Open Resource File* → `resources.qrc`.
2. In the **Action Editor** create `actionOpen`, … and pick an icon → *Choose Resource…*.
3. Drag the actions onto the menu and the toolbar.
4. Save. The `.ui` now contains `<include location="resources.qrc"/>`.

## ⚠️ The naming rule
Because of that include, uic generates this line in `ui_main_window.py`:
```python
import resources_rc
```
So the rcc output **must** be named `<qrc name>_rc.py`:
```bash
pyside6-rcc resources.qrc -o resources_rc.py   # ✅
pyside6-rcc resources.qrc -o rc_resources.py   # ❌ ModuleNotFoundError: resources_rc
```
`build.sh` follows this rule.

## Stylesheets (QSS)
CSS-like syntax with Qt selectors:
```css
QToolButton:hover { background: #ebf4ff; }   /* type + pseudo-state */
QLabel#imageLabel { background: #edf2f7; }   /* objectName, like a CSS id */
```
We load it from resources and apply it to the **whole app**: `app.setStyleSheet(load_stylesheet(":/styles/style.qss"))`.
You can also call `widget.setStyleSheet(...)` for a single widget, or set `styleSheet` in Designer.

## Other things shown here
- `QMainWindow` anatomy: menu bar, toolbar, central widget, status bar.
- `QAction` is **one** object used in a menu *and* a toolbar, with one shortcut and one handler.
- `QScrollArea` + `QLabel.setPixmap` for images. `QPixmap.scaled(..., KeepAspectRatio)`.
- `QFileDialog.getOpenFileName`, `QMessageBox`.

## Common mistakes
- Editing an icon and forgetting to **rerun rcc** → the old icon is still embedded.
- Naming the output `rc_resources.py` → `ModuleNotFoundError` from the generated UI file.
- Using `open(":/styles/style.qss")` → `FileNotFoundError`. Use `QFile`.
- Huge files (videos, datasets) in a `.qrc` → giant `.py` files and slow startup. Keep resources small.
